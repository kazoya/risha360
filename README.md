# ريشة 360

منصة تسويق عربية على Next.js مع PostgreSQL (Neon).

```bash
npm install
npm run dev
```

انسخ `.env.example` إلى `.env.local` وضع `DATABASE_URL` و`DESK_TOKEN`. لوحة المالك على `/desk`.

الحفظ لا يرسل واتساباً ولا بريداً. كتالوج الأدوات مأخوذ من الصفحات العامة لمرآة 3aqel، والأدوات غير المعلّمة «تعمل في المتصفح» لا تولّد ملفات.
